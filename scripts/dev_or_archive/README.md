# Development and archived scripts

Put one-off debugging helpers, superseded experiment drivers, and non-supported local utilities here.

Scripts in this directory are not part of the supported BeltMap CLI surface and should not be cited as paper evidence without being promoted into a current paper experiment or package CLI.

Use this directory when a script:

- was useful for diagnosis but is no longer part of the current evidence path;
- depends on local paths or temporary artifacts;
- produces exploratory output that should not be interpreted as citable metrics;
- is kept only for provenance.

Prefer adding a short header comment to each archived script explaining why it is archived and what current command supersedes it.
